<task type="auto">
  <name>Task 1: Login page</name>
  <files>package.json, src/server.js, views/login.ejs, public/css/app.css, public/js/firebase-config.js, public/js/login.js</files>
  <action>
    - `npm install ejs@7.0.2`. In server.js set the `ejs` view engine, serve `public/` statically, add `express.json()` and `app.set('trust proxy', 1)`.
    - `firebase-config.js` exports the web config. It is public by design, so commit it.
    - `login.ejs` follows the DESIGN.md login layout: a wordmark, a Google button, an email/password form and a message area.
    - `login.js` is an ES module that imports Firebase 13.4.0 from gstatic. It signs in with `signInWithPopup` or `signInWithEmailAndPassword`, then sends `getIdToken()` as JSON to `/session`. On success it goes to `/`. On failure it shows the server's message and calls `signOut()` so another account can be tried.
  </action>
  <done>GET /login renders both sign-in options with no console errors</done>
</task>

<task type="auto">
  <name>Task 2: POST /session</name>
  <files>src/routes/auth.js, src/server.js</files>
  <action>
    - `GET /login` renders the login view.
    - `POST /session`:
      - Reject a cross-site request with 403: check `Sec-Fetch-Site`, and fall back to `Origin`.
      - `verifyIdToken(idToken, true)`. Require `auth_time` within the last 5 minutes.
      - If `email_verified` is false, return 403 with the D-12 verify message. If `admin !== true`, return 403 with the D-12 "isn't an admin" copy.
      - `createSessionCookie` with a 14-day `expiresIn`. Set the `session` cookie with `{ maxAge, httpOnly: true, secure: production, sameSite: 'lax', path: '/' }` and return `{ ok: true }`.
      - On any other error, return 401 with `{ error }`.
  </action>
  <done>Each refusal returns its own message; the success path sets the cookie</done>
</task>
