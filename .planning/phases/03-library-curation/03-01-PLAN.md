  <action>
    - `src/exercises.js`:
      - `loadLists()` reads `muscleGroups`, `targetMuscles` and `equipment` into id-to-name maps. These are about 35 docs, read on every request.
      - `listExercises({ q, limit })`: with no search words, `orderBy('name')`. With search words, `where('searchTokens', 'array-contains', words[0]).orderBy('name')`, then keep docs whose tokens contain every other word. Fetch `limit + 1` docs to get `hasMore`.
      - `status(doc)` gives archived, then edited, then imported.
      - `still(url, transform)` builds sized URLs by inserting the transform after `/upload/` in the stored `url`. This needs no Cloudinary secret on Vercel.
    - `src/routes/exercises.js`:
      - `GET /exercises` and `GET /exercises/:id` render one view.
      - `limit` is clamped to a multiple of 30 between 30 and 900.
      - The `:id` route reads that doc. If it is missing, or Firestore rejects the ID, the page shows "No exercise with that ID" with status 404.
      - A query error logs `err.message`, which for a missing index includes the link that creates it, and shows a short error on the page.
    - `server.js` mounts the router on `/admin` after `requireAdmin`.
    - `views/partials/topbar.ejs` is taken out of admin.ejs and adds the Exercises tab. Lists comes later.
    - `views/exercises.ejs`:
      - A GET search form on `q`, and the rows as links that keep `q` and `limit`.
      - Load more points to `?q=..&limit=+30#row-{old limit}`.
      - The empty search copy is from DESIGN.md.
  </action>
